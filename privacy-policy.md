# SOHO - Politica de privacidad / Privacy Policy

Ultima actualizacion / Last updated: 2026-11-01

## Espanol

SOHO es una aplicacion de escritorio que se instala y funciona en la computadora de cada usuario. Sirve para ver las metricas de sus propias campanas de Meta Ads junto a sus ventas.

1. Que datos usa SOHO
   - La llave (token de acceso) de Meta que el propio usuario genera y pega en la app.
   - Metricas de las cuentas publicitarias del usuario (gasto, impresiones, clics, resultados, nombres de campanas, conjuntos y anuncios), leidas con la API de Marketing de Meta.
   - Los datos de ventas que el usuario conecte (por ejemplo, su propia Hoja de Google).

2. Donde se guardan
   - Todo se guarda solo en la computadora del usuario (carpeta %APPDATA%\SOHO\datos en Windows).
   - SOHO no tiene servidores propios, no envia estos datos a terceros y no los vende ni los comparte.
   - La app solo se comunica con Meta (graph.facebook.com) y con las fuentes que el usuario conecte.

3. Para que se usan
   - Unicamente para mostrarle al usuario sus propios reportes dentro de la app. No se usan para publicidad, perfiles ni ningun otro fin.

4. Datos de terceros
   - SOHO no recopila datos personales de usuarios de Facebook o Instagram. Solo lee metricas agregadas de las cuentas publicitarias del propio usuario.

5. Control y eliminacion
   - El usuario puede borrar sus datos en cualquier momento. Ver: https://raw.githubusercontent.com/tech343232/soho-legal/main/data-deletion.md

6. Contacto
   - https://github.com/tech343232/soho-legal/issues

## English

SOHO is a desktop application installed and run on each user's own computer. It shows the user's own Meta Ads campaign metrics next to their sales.

1. Data used: the Meta access token the user generates and pastes into the app; aggregated metrics of the user's own ad accounts (spend, impressions, clicks, results, campaign/ad set/ad names) read through the Meta Marketing API; and the sales data the user chooses to connect.
2. Storage: everything is stored only on the user's computer (%APPDATA%\SOHO\datos on Windows). SOHO has no servers of its own and does not send, sell or share this data with third parties. The app only talks to Meta (graph.facebook.com) and the sources the user connects.
3. Purpose: only to show the user their own reports inside the app. Never used for advertising, profiling or any other purpose.
4. Third-party data: SOHO does not collect personal data of Facebook or Instagram users. It only reads aggregated metrics of the user's own ad accounts.
5. Deletion: see https://raw.githubusercontent.com/tech343232/soho-legal/main/data-deletion.md
6. Contact: https://github.com/tech343232/soho-legal/issues
